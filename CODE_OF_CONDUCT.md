# Code of Conduct

We want this project to remain a respectful and useful place for people learning and improving retrieval-augmented generation systems.

## Expected behavior

- Be respectful and specific when discussing code or documentation.
- Assume good intent while still asking for reproducible evidence.
- Welcome contributors with different experience levels and language backgrounds.
- Keep feedback focused on the work, not the person.
- Protect private information, credentials, and unpublished vulnerability details.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disruption, spam, credential exposure, and publication of another person's private information are not acceptable.

## Enforcement

The maintainer may edit or remove content, close discussions, or restrict participation when behavior conflicts with this policy. To report conduct privately, contact the maintainer through the GitHub profile linked in the README. Reports will be reviewed as confidentially as practical.
